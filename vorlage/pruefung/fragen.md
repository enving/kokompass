# Kontext-Test (frische Sitzung, ohne Suche)

Eine neue Sitzung soll nach `kompass` ohne weitere Suche richtig antworten. Erwartete Antwort in Stichworten
daneben; stimmt sie nicht, fehlt etwas in `person/` oder in der Startausgabe.

| Frage | Erwartet |
|---|---|
| Wer bin ich und als was will ich wahrgenommen werden? | |
| Welche Ziele gelten gerade? | |
| Was ist diese Woche dringend? | |
| Was darf ein Agent nie tun? | |
